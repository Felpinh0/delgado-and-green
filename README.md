# delgado-and-green
Sistema para registrar propriedades, talhões, culturas e medições de campo, com API e painel de visualização. Projeto de estudo que une programação e agronomia.

## Status

Em desenvolvimento. Fase atual: preparação e fundamentos de Python.

## Como rodar

com o Python 3 instalado, execute no terminal:

'''bash
python src/conversor.py
'''

O programa mostra a conversão de 10 ha para alqueires paulistas.

## Tecnologias planejadas

- Python e FastAPI
- PostgreSQL ou SQLite
- HTML, CSS e JavaScript
- Docker e GitHub Actions
